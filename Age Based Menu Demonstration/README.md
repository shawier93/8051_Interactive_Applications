# Age-Based Menu Demonstration

[Repository overview](../README.md)

Demonstrate a menu that selects a stored response according to an age band or another menu choice.

## Implementations

The memory version stores a response code. LCD versions display the archived messages, with different port assignments. The Proteus-derived version is another source listing for the same type of menu.

| Implementation | Input | Output |
| --- | --- | --- |
| [LCD Port 0 Interface](LCD%20Port%200%20Interface/README.md) | Stored values or prompted choices | LCD and internal result bytes |
| [Memory Age Band Selection](Memory%20Age%20Band%20Selection/README.md) | Values stored in memory | Internal memory |
| [LCD Port 1 Interface](LCD%20Port%201%20Interface/README.md) | Stored values or prompted choices | LCD and internal result bytes |
| [Proteus Age Band Menu](Proteus%20Age%20Band%20Menu/README.md) | See example | See example |
