# 8051 Interactive Applications

[Back to portfolio](https://github.com/shawier93/Projects-using-Assembly-for-8051)

Follow questions, choices, and retry paths in small menu-driven applications.

## Applications

| Application | Description |
| --- | --- |
| [Math Practice and Scoring](Math%20Practice%20and%20Scoring/README.md) | Present arithmetic questions, compare the answers with the program’s answer key, and update a score. |
| [Age-Based Menu Demonstration](Age%20Based%20Menu%20Demonstration/README.md) | Demonstrate a menu that selects a stored response according to an age band or another menu choice. |
| [Appointment Registration Demonstration](Appointment%20Registration%20Demonstration/README.md) | Demonstrate a registration menu that uses status answers and a month to select a stored appointment response. |
